# Scored Next-Content Backlog — No Publishing Authorization

This is a planning backlog only. It does not authorize a new MDX article,
promise search demand, or claim that an official source is currently available.
Checkpoint 3 had no current URL-level GSC export, keyword-volume dataset, or
completed live source review, so the scores are hypotheses for research order.

## Scoring method

- **Commercial intent (1–5):** proximity to a task where a user may adopt a
  legitimate tool, membership, or disclosed service.
- **Opportunity (1–5):** expected usefulness and gap relative to the existing
  59-page cluster, not verified search volume.
- **Source availability (1–5):** preliminary likelihood that first-party NOUN
  evidence can support the page. This is not a live verification.
- **Difficulty (1–5):** research/freshness burden, where 5 is hardest.
- **Priority score (maximum 20):** commercial intent + opportunity + source
  availability + (6 − difficulty).

## Priorities

1. Research ranks 1–2 only after the 49 existing rewrite dispositions are
   triaged; strengthening current pages outranks expanding the site.
2. Require at least one authoritative first-party source and a named reviewer
   before drafting.
3. Use GSC query/page evidence, if later made available, to rescore opportunity
   and avoid cannibalising an existing intent.
4. Do not publish deadline, charge, eligibility, or document-list claims without
   a dated source review and a visible change-risk caveat.
